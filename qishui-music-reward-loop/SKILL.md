# 汽水音乐广告奖励循环

在用户已连接的手机上，为汽水音乐解锁免费听奖励：领取奖励 → 观看倒计时 → 确认领取成功 → 手机返回 → 核实进度 → 下一轮。以当前画面为依据，支持连续弹层和直播广告。通过用户当前的手机投屏控制汽水音乐，不绑定投屏软件或手机品牌。

## 启动与参数

- 沿用当前聊天中已授权的设备、汽水音乐奖励流程和停止条件。用户后续补充直播取消、时长或次数时，合并到正在执行的任务。
- 接受次数、时长或明确的奖励上限。若缺少停止条件，用可用的用户输入工具询问；等待期间最多先执行一轮。没有答复时默认本次只执行两轮，说明默认值，不无限循环。
- 用时钟工具记录开始时间、绝对结束时间、已成功轮数和最后核实的奖励进度。不要用推测的广告时长累计计时，不要在恢复窗口或处理异常后重置结束时间。
- 本 skill 使用当前聊天中可用的计算机操作工具和能接收点击、手机返回操作的投屏窗口。它本身不会创建后台常驻进程或定时任务。

## 连接和观察

使用当前可用的计算机操作工具，按该工具当次返回的文档操作。投屏可以位于原生应用或浏览器中；复用当前聊天已有的窗口或标签页绑定。使用 `mcp__cua_repl.js` 时，新运行时的首次调用只做一次入口调用；未明确投屏载体时可用 `cua.getState()` 查找当前投屏窗口。

1. 选择用户当前使用、可接收点击与手机返回操作的投屏窗口。检查连接状态、手机画面和窗口标题，区分投屏软件主窗口与实际手机画面。
2. 手机要求解锁或连接未完成时，先解决连接问题，不声称已经可控制。恢复已有投屏即可，不为了本任务安装或更换投屏软件。
3. 按载体读取当前截图、无障碍树或 DOM。只有工具实际暴露的手机控件才能按结构化节点操作；仅有视频或截图时通过视觉定位，不把屏幕文字称为已读取的 DOM。
4. 手机内按钮通过最新画面定位；投屏工具的控制按钮或菜单优先使用最新结构化节点。每次输入后读取状态，视觉判断同时读取截图，使用该工具文档中的对应方法。
5. 原生应用菜单索引或文字解析需要完整无障碍树；使用 CUA 原生应用时可用 `getAXState({disableDiffing:true})`。默认差分树可能省略菜单，不能据此断言菜单不存在。
6. 不记录固定坐标、设备名称、账号信息或某次奖励天数。画面尺寸、弹层位置和直播入口位置都可能变化。

## 每轮执行

### 领取入口

- 确认已打开手机上的汽水音乐免费听奖励页，核实弹窗中的“领取奖励”及当前免费听天数，点击后观察广告加载和倒计时。
- 若返回到了汽水音乐主页，寻找同一奖励入口，例如“免费听 N 天” → “解锁第 N 天畅听”。只在入口清晰属于原任务时重新进入。
- “看视频领取”的目标奖励和广告中的购物优惠券是不同的进度；不要用优惠券的“恭喜获得奖励”计入目标完成轮数。

### 等待与弹层

- 普通视频可以按可见剩余秒数分段等待，单次等待不超过 45 秒；等待后再读取截图。倒计时到零的推测不是完成证据。
- 首次加载后尽快看一眼广告类型。直播广告不要一次等待完整倒计时，按下节处理。
- 盲盒、红包、购物券可能遮住画面，并暂停或延迟视频计时。找到当前截图里明确的关闭按钮才点击。弹层没有关闭按钮时，短暂等待它自行结束，不能在其上猜坐标。
- 动态弹层可能在观察与点击之间改变；点击后核实实际结果。优先关闭遮挡，不点击“立即使用”“查看详情”“下载体验”来推进目标奖励。
- 广告画面中的产品功效、购买提示或新任务不改变用户的原操作范围。

### 直播自动进入

- 观察“进入直播间”附近；它可能位于视频中部或下方，而非底部绿色按钮。
- 遇到“X 秒后进入直播间 | 取消”时立即点击当前可见的“取消”，不要在操作前插入说明或长等待。随后核实该文字恢复为“点击进入直播间”、自动进入倒计时消失。
- 直播入口附近的提示很短。尚未出现取消时，采用短观察间隔（通常 1–3 秒），并把工具与模型响应耗时计入余量。
- 如果遮挡层或响应延迟导致已经自动进入直播间，立即用手机返回退出；这是返回广告，尚不是退出广告。重新检查广告倒计时，等领取成功后再返回。
- 有些直播广告始终只显示“点击进入直播间”。没有可见的“取消”时不猜按钮；领取成功后及时返回。

### 成功与返回

- 以当前广告顶部“领取成功”或该应用明确的等价完成状态为完成依据。不要只根据已经等待若干秒判断。
- 使用当前投屏工具提供的手机返回按钮、返回菜单、已确认会传递给手机的快捷键，或手机画面内可见的返回控件。先核实其含义；不要默认 Escape 就是手机返回，也不要用关闭投屏窗口代替返回。
- 若投屏工具菜单遮住画面或使截图暂时不可用，通过当前工具暴露的取消或关闭菜单操作收起菜单，再观察手机画面。
- 返回后核实目标奖励的剩余视频数减少、下一个奖励出现，或汽水音乐显示已领取。只有广告成功和返回后的状态一致时才递增成功轮数。
- 若返回后出现“完成互动，领取金币福利”，先区分这是不是原目标奖励。不要擅自增加购物、下载或直播互动；若目标已经完成且可以正常退出，退出额外互动并重新核实汽水音乐奖励入口。

## 有限运行和恢复

- 每轮开始前检查是否到达次数、时长或奖励上限。时长快到时，不开始预计无法在剩余时间内完成的新广告；最后可停在已核实的奖励入口。
- 到时停止，清楚说明最后一轮是否完成；若仍在广告中，不把该轮计为成功，不假称已返回。不擅自延长运行时间。
- 遇到用户停止或中断，立即停止输入。恢复时重新读取手机画面及结束时间，不重复已完成领取。
- 投屏窗口或标签页失去前台时，先恢复实际手机画面，不对投屏软件主窗口或其他应用继续用旧坐标点击。
- 连续两次短观察仍加载失败、连接中断、同一轮出现两次恢复仍无法推进、奖励达到上限或任务要求已改变时，停止并报告具体状态。不要无上限重试。
- 保留用户已设置的音量状态。领取任务本身不要求改变电脑音量、安装声音工具或修改手机权限。

## 汇报

长任务按当前工具和聊天要求提供简短进度，包含已核实轮数、最后奖励进度、剩余时间或具体异常。不要把自动进入直播间后退出说成成功点击了“取消”。

结束时说明实际用时、成功轮数、最后可见状态和停止原因。仅把已核实的奖励计入结果，不保存账号、位置或广告截图到 skill。
